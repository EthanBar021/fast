# Fast

Application iPhone de mesure en voiture : vitesse, forces G et trajet.
Bêta personnelle 

## Stack

Expo SDK 58 · React Native · TypeScript · expo-router · Reanimated · expo-sqlite

## Lancer en développement

```bash
npm install
npx expo start
```

Ouvrir le QR code avec Expo Go sur l'iPhone 

## Vérifications

```bash
npm run typecheck
npm run lint
npm test
```

## Build iOS

`.ipa` non signé via GitHub Actions
